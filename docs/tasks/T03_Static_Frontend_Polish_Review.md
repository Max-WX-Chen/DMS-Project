## 预约分类

后台通用的 `.btn` 样式也用于站内按钮，会给链接加深绿色背景和 7 像素圆角。原先 `bookings.html` 和四个预约结果页把该类误用于未选中的分类链接。其他三种分类页使用普通链接，所以背景会在切换页面时消失。

统一八个预约页面的分类导航。分类链接现在使用原有的下划线规则，仅当前分类高亮，并通过 `aria-current` 标注，方便浏览器与辅助技术识别。同一组按钮的目标页面与分类记录保持对应。

## Members 搜索如何演示

管理员页面展示四位样例会员。`member-search.html` 通过一个固定查询展示 An Lifeng 的一条结果。现在用预设的只读字段和 **View An Lifeng search example** 说明样例。点 **Show all sample members** 回到四条名单。

真实搜索需要程序读取输入并筛选。浏览器 JavaScript 可以筛选内置数据。正式后台搜索应由 PHP 接收姓名、会员编号或邮箱，在确认管理员权限后查询数据库并返回结果。静态交付包继续使用 HTML/CSS 和固定示例，符合课程本阶段范围。

其他静态页的预约状态、收款结果、签到结果和报表数字也随页面写入。要验证真实支付、名额、签到和报表计算，需要等动态阶段接入数据库。
