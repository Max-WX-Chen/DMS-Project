**已设计并实现**：11 类实体、10 组核心联系。订单引用不可改价的套餐版本，会籍经来源订单确定购买人及套餐。金额由成交版本取得。订单和付款键分别在会员、订单范围内保持唯一。受限用户可更新订单状态，仅具业务所需的写权限。

**已验证**：在新建的 MariaDB 10.4.32 实例上导入 SQL，用 Apache 2.4.58/PHP 8.2.12 验证登录、注册、重复邮箱、CSRF、角色限制、姓名/邮箱搜索接口、停用使既有会话失效。HTTP 测试使用分别登录的两个 cookie 会话并发确认同笔订单、并发续费两张不同订单，分别得到一个会籍周期、两个首尾相接的周期。覆盖模拟失败、失败重试、线下确认、取消、他人订单读写，以及买完会籍后成功预约和取消。

**故障复现**：测试触发器让最后一步“插入会籍”抛错。检查原订单仍为 PENDING，付款表和会籍表均无关联行，移除故障后重试成功。T06/T12/T13 专项脚本通过 10 项断言，包括历史改价、第二次成功付款、外键保护、测试预约级联删除和回滚。独立执行安装脚本生成的账号能真实结算、预约、维护资源，并被拒绝删除、建表和修改订单成交字段。

**环境记录**：首次隔离实例出现 Windows InnoDB 异步 I/O 等待，换用独立数据目录与缓冲 I/O 后完成复验。安装账号验证中修复了该隔离实例的 Aria 列权限表索引，随后配置脚本通过。所有测试均针对工作目录下的测试数据。
