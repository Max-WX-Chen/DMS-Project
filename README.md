## 六人分工

- A 组：需求、ER、逻辑设计，后续负责数据生成、验证、报告与 PPT 汇总。
- B 组：静态与动态前端。
- C 组：数据库实现与后端业务。
- 全员：规则评审、理解关键设计、联调、展示与验收。

## 协作方式

`main` 作为全组共同使用的正式基线。各项任务在独立分支开发，通过 PR 审阅和合并进入 `main`；文件可以在 `main` 的不同目录中保存，不必全放根目录。

每次 Codex 产出均附 Markdown，解释任务、原理、验证与交接。具体业务和技术要求以总框架及相应任务文档为准。
